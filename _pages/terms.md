This is a personal website. It uses no cookies, analytics, advertising or comment services, and it loads no content from third parties.

## Hosting
The site is hosted on GitHub Pages. GitHub logs visitors' IP addresses for security purposes, as described in [What is GitHub Pages?](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).

## Theme setting
If you switch between the light and dark theme, your choice is saved in your browser's local storage. It stays on your device.

## Email
If you email me, I use your message only to reply to you.
